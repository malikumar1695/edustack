  - **Install saga, worth remembering**: ran three `npm install` attempts concurrently in the background without confirming the first had actually finished — they raced on the same `node_modules` tree and corrupted it (`TAR_ENTRY_ERROR`/`ENOTEMPTY` on `antd`). Lesson: never start a second background install against the same `node_modules` before a task-completion notification confirms the first is done — a "still running 20 minutes later" install is normal for a 2000+ package tree, not a sign to retry.
